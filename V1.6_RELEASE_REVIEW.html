Before You Order V1.6 Release Review

Verdict: ready for Google Play internal testing after two stale preference-related guidance strings were corrected and covered by a regression test.

Findings

Fixed: empty-state and blacklist guidance still referred to removed dietary and budget controls. English and Chinese copy now points to active cuisine/food filters and the contextual hidden-food manager.

Accepted toolchain note: npm audit reports moderate issues in Expo's transitive iOS build parser path (xcode → uuid 7.0.3). The offered forced fix would downgrade Expo to SDK 46, so it was not applied to this SDK 57 Android build.

Remaining boundary: this review does not replace hands-on testing across a representative set of Android screen sizes and Google Maps app/browser combinations.
