| --- | --- |

## Recommendation contract

Candidate filtering is pure and excludes hidden IDs before sampling. With multiple candidates, the current ID is removed; one remaining candidate is valid and zero candidates returns null. The generic sampler accepts `[0, 1)` RNG values and ignores non-positive/non-finite weights.

Choice affinity is `min(3, 1 + chosenCount × 0.25)`. The sampling weight is `0.2 + 0.8 × affinity`, giving a bounded range of 1–2.6. The 0.2 baseline is an exploration component, not a claim that exactly 20% of draws are uniformly random. A never-chosen dish retains weight 1. Any valid Not today event within the last 72 hours multiplies the weight by 0.1, even if followed by a choice. At exactly 72 hours the reduction expires. Feedback order does not affect weights. Choosing does not apply the previous 20-hour penalty.

Repeated taps on the same saved action are guarded against duplicate choice writes. Saving never scrolls or resamples; new different results request one cancellable, animated scroll. All randomness tests use fixed RNG values, not statistical thresholds.

## Storage and failures

The existing SQLite tables and file name are preserved. Tests execute the same SQL through Node SQLite, including disk close/reopen, blacklist undo/restore-all, language and settings persistence. Native Expo SQLite remains a device-QA item.

After a successful blacklist read, subsequent database failures retain cached hidden IDs and keep changes in memory for the session. The UI warns that temporary choices will not survive restart. If the blacklist cannot be read during startup, dish suggestions pause rather than risk suggesting previously hidden meals; venue mode still works. Restart retries the database. There is no destructive database recovery or automatic overwrite of stored records.

Map searches include English, Chinese, existing Malaysian aliases and mode keywords. Strategy labels describe searches; the app does not fetch ratings, distances, availability or opening status. Maps provides the external results. Delivery exposes selectable dish text with instructions to long-press, copy and paste into Grab/Foodpanda. There are no fabricated delivery deep links and no Places API.
