# V1.8 local image and catalog review — 6 September 2026

> Completion update — 10 September 2026: the current V1.12 catalog supersedes the historical placeholder counts below. It displays 217 reusable source photos and 27 disclosed AI-assisted original food images, with zero placeholders and zero withheld mappings. The current hash-bound decisions are in `V1.8_CATALOG_REVIEW.json`; the sections below preserve the V1.8 review history that motivated the replacements.

All 244 current local WebP assets were inspected in 21 numbered contact sheets, alongside the bilingual catalog descriptions and explicit food categories. The review ledger records each image SHA-256, sheet/cell, display decision and category decision: [V1.8_CATALOG_REVIEW.json](V1.8_CATALOG_REVIEW.json). Catalog validation rejects stale images, names, descriptions, categories or display decisions. A ledger update requires another review; do not regenerate it merely to make validation pass.

All original image files are unchanged. The catalog contains 191 imported photo records and 53 original artwork records. The initial 36 withheld images plus 18 newly identified conflicts give **54 withheld photographs, 137 displayed photographs and 107 native neutral placeholders**. Both original placeholders and withheld photos use translated native content in recommendation/history cards. Credits retain the source information for traceability.

This is a visual/semantic review at contact-sheet resolution, not a tasting review or native-device acceptance. A retained photo means no obvious dish conflict was found; it does not independently prove source-to-file identity or photographer ownership. Actual Android crops, font scaling and accessibility remain unverified.

## Catalog decisions

- Reviewed all 244 explicit food categories against both descriptions. Idli with sambar changes from bread/soup to light/soup: steamed rice cakes are not bread. Other categories remain under the documented serving-form convention; soup includes gravy curries and categories can describe alternative servings.
- Renamed Spaghetti carbonara to Pasta carbonara so the name accommodates the pictured linguine. The Chinese name and stable meal ID remain unchanged.
- No dishes or existing feedback IDs were removed.

## Processing and author records

Each of the 244 credit records now has explicit modifications and attribution status. Imported photographs record crop, resize and WebP conversion, matching the existing ImageOps.fit(900, 600) pipeline in scripts/fetch_wikimedia_meal_images.py. Original artwork records say original-artwork. Card cropping is described separately. This records the repository processing pipeline; it is not a new source-download audit.

The in-app credits show the bilingual dish name, credited source title, artist, license, per-image modifications and working source/license links. Source-link failures now use a browser-link error with retry, rather than a Maps error.
